# Retalhos

Controle de estoque de retalhos de MDF integrado ao Corte Certo Plus.

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python main.py          :: executa o app
.venv\Scripts\python -m pytest        :: roda os testes
```
